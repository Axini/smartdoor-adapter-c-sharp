    AdapterCore ->> Handler: Subscribe to OnError, OnResponse events
    
    note right of AdapterCore: AdapterCore instantiated<br>State: Disconnected
    
    Adapter ->> AdapterCore: Start()
    AdapterCore ->> Broker: Connect()
    Broker ->> AMP: Connect()
    AMP -->> Broker: Connection Successful
    Broker -->> AdapterCore: Connection Successful
    AdapterCore ->> Broker: AnnounceAdapterWithAMP()
    Broker ->> AMP: SendAnnounceMessage(name, handler.SupportedLabels)
    AMP -->> Broker: Confirmation Received
    
    note right of AdapterCore: State: Announced
    
    AMP ->> Broker: Send Configuration
    Broker ->> AdapterCore: Handle configuration
    AdapterCore ->> Handler: Set Configuration
    AdapterCore ->> Handler: Start()
    Handler -->> Broker: Ready
    Broker -->> AMP: Ready
    
    note right of AdapterCore: State: Ready
    
    AMP ->> Broker: Send label
    Broker ->> AdapterCore: Handle label
    AdapterCore ->> Handler: Stimulate(label.ToSutMessage())
    Handler ->> SUT: Stimulate SUT
    Handler -->> AdapterCore: Response received
    AdapterCore ->> Broker: SendStimulusToAMP
    Broker ->> AMP: Send label
    
    AMP ->> Broker: Send Reset
    Broker -->> AdapterCore: Handle reset
    AdapterCore ->> Handler: Reset()
    AdapterCore ->> Broker: SendReadyMessage
    
    AMP ->> Broker: Close
    Broker -->> Broker: Close()
    Broker ->> AdapterCore: HandleClose()
    AdapterCore ->> Handler: Stop()
    
    note right of AdapterCore: State: Disconnected
